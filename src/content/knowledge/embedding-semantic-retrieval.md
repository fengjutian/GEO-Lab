嵌入（embedding）解决的是一个具体问题：如何在不做逐字匹配的前提下，判断两段文本是否在讲同一件事。它的做法是把文本映射到一个高维向量空间，让语义相近的文本在空间中距离更近。检索系统因此在语义层面而不是字面层面上工作，这既是 GEO 的机会，也是它的盲区。

## 从 token 到向量：模型在学什么

现代嵌入模型通常基于 Transformer 编码器，通过对比学习训练：把语义相同的句子对拉近，把无关的句子对推远。Sentence-BERT 是这类方法的代表工作，它把句子的编码从逐 token 表示压缩为单个句向量，使相似度计算从交叉编码的平方复杂度降为一次点积。

训练目标决定了模型的“语义”是什么。它学到的是语料中反复出现的共现模式与改写关系，而不是逻辑推理。这一点解释了后面的所有失效场景。

## 相似度：为什么用余弦而不是欧氏距离

多数嵌入模型的输出会被归一化到单位长度，此时余弦相似度与欧氏距离单调等价：

```text
cos(a, b) = (a · b) / (|a| · |b|)
```

归一化后 |a| = |b| = 1，于是余弦相似度退化为点积。工程上直接用点积，省掉一次开方与除法，这也是向量数据库普遍支持内积索引的原因。

需要警惕的是：**相似度的绝对值没有统一含义。** 同一个 0.7，在不同模型、不同语料域上的含义可能完全不同。判断检索质量时，应该看同一查询下的相对排序，而不是跨模型比较绝对值。

## 模型选择：四个实际维度

| 维度 | 影响 | 实践建议 |
| --- | --- | --- |
| 语言覆盖 | 中文/跨语言检索质量 | 中文任务优先选多语言或中文专精模型 |
| 维度 | 存储成本与区分度 | 768–1024 维是常见平衡点；降维需重新评估 |
| 最大输入长度 | 单次编码的文本上限 | 超过模型上限的部分会被截断，务必对齐 chunk 大小 |
| 领域适配 | 专业术语的表征 | 通用模型在垂直领域常需微调或换用领域模型 |

最后一条最容易被忽略。通用嵌入模型在技术文档、医疗、法律等领域的表现常常明显下降，因为训练语料里这些词汇的共现模式稀疏。这也是“领域内容要不要自建检索”这个问题的核心。

## 字面匹配与语义匹配：失败模式互补

两种检索不是替代关系：

- **字面匹配失效**：查询写“生成式引擎优化”，文档只写“GEO”；或反过来。BM25 无法识别这是同一个概念。
- **语义匹配失效**：查询是产品型号 `GPT-4o-mini`，模型可能把 `GPT-4o` 也排到前面；精确标识符、编号、人名在向量空间里容易坍缩。

因此混合检索是默认方案。对内容生产者来说，这转化成一个非常具体的写作要求：**在页面里同时出现概念的完整名称、常见缩写与具体实例**，让两条检索路径都能命中。

```text
查询：GEO 怎么做
页面 A：「生成式引擎优化（GEO）通过……」
页面 B：「GEO 通过……」
页面 C：「生成引擎优化即 GEO，具体做法包括……」

对 BM25：A、B、C 都能命中 "GEO"
对稠密检索：A 与 C 语义覆盖更全，因为完整名称提供了更多上下文
```

## 常见失效场景

1. **否定与条件**：“不含麸质”与“含麸质”在向量空间里可能非常接近，因为句子结构相似。这类差异必须靠字面或规则补充。
2. **数字与单位**：“支持 100 并发”与“支持 1000 并发”的向量几乎相同，但事实完全相反。
3. **专有名词**：未登录的品牌名、人名、型号容易被映射到相近的常见词。
4. **长文本**：一篇 5000 字的文章编码成一个向量，主题会被平均掉。这直接引出切分的必要性。

## 对 GEO 的含义

嵌入模型决定了“内容与查询是否讲同一件事”这一判断。它不会因为你重复关键词就提高相关性——重复只会让向量集中在少数维度上，反而降低区分度。

真正有效的做法与人类写作规范一致：

- 首次出现概念时给出完整名称与定义，之后再使用缩写。
- 用具体实例与数据锚定抽象概念，增加可匹配的语义特征。
- 覆盖同一概念的不同表述（同义、上下位、场景化描述），但不要机械堆叠。
- 保证段落主题单一，避免一个 chunk 混入多个主题导致向量被平均。

可以在 [Embedding 相似度实验](/tools/embedding/) 里直接观察这些效应：把“GEO”和“生成式引擎优化”分别输入两段文本，你会发现哈希向量给出低分——这恰好演示了字面匹配的局限，也说明为什么真实系统必须依赖预训练嵌入模型。

## 小结

嵌入把语义判断变成了几何计算，代价是它只能反映训练语料中的共现模式。对内容而言，这意味着可检索性来自“讲清楚”而不是“重复够多”：完整表述、具体实例、单一主题的段落，是对稠密检索最友好的形态。
